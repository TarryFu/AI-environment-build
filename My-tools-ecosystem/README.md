# My Tools Ecosystem）

本文件夹是专门介绍我个人工具链的索引与说明，汇总我在科研与工程工作中经常使用的各类工具。这些工具按照用途大致分为以下几个方向：

- **论文（Papers）**：论文检索、阅读、管理、写作与排版相关的工具。
- **代码（Code）**：编程开发、版本管理、调试、部署与环境搭建相关的工具。
- **其他文字资料（Text Materials）**：笔记、文档、知识管理与文字处理相关的工具。
- **画图（Drawing）**：用于绘制结果图、框图、流程图的绘图与可视化工具。

此外，本文件夹还会介绍 **workflow（工作流）**，即如何将上述各类工具串联起来


> 详细内容请参阅 [Tools-ecosystem and Workflow.md](./Tools-ecosystem%20and%20Workflow.md)。
